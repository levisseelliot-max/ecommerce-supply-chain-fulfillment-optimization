## 🎯 Dashboard Focus

The dashboard provides an executive view of:

- 📦 **Fulfillment performance**
- ⏱️ **Lead-time and delivery performance**
- 🚚 **Supply chain bottlenecks**
- 📊 **Operational performance indicators**
- 💰 **Financial impact of fulfillment issues**
